Since only one runner works at a time, any idea still "running" at this point was left behind by a run that stopped: put each back to "pending" (progress 0, stage "", startedAt "") so it is redone first. If you ever find heartbeat cleared but local git state suggests a push is mid-flight (e.g. a merge left uncommitted), treat that as a crashed run: finish or cleanly abort it before releasing.

SETUP (once per run, only after the heartbeat above is yours): `git fetch origin`, then `git checkout -B idea-queue origin/idea-queue`, then `git merge --no-edit origin/main`. If there are conflicts, resolve them by hand, keeping everything from main and re-applying the queue's changes on top. Never drop main's changes. Commit the merge. Then `pip install -q flask` so the safety check can load the app.

SAFETY CHECK: `python3 tools/predeploy_check.py` must print OK (syntax, url_for routes, template paths, and the db.py foreign-key-guard check) before you push anything.

LOOP (see WHEN TO STOP below):
A0) ROLL BACK REQUEST (always first, before a deploy request or any idea): read meta/deploy. If rollbackStatus is "requested" and rollbackDoneAt is empty or earlier than rollbackRequestedAt:
