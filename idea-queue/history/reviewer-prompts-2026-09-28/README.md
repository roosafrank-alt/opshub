# Reviewer routine prompts, as set on 2026-09-28

These three files are a copy of what the nightly/daily reviewer routines were
told on 2026-09-28, when the "queued work, not yet deployed" rules were added:

- `nightly-bug-tester.md` - Idea Queue nightly bug tester (all apps)
- `daily-design-review.md` - Idea Queue daily design review (all apps)
- `feature-suggestions.md` - Idea Queue feature suggestions (all apps)

They are a record, not a source: each routine holds its own prompt, and nothing
reads these files. If a reviewer's prompt is changed, drop a fresh dated copy in
here rather than editing these. (The Idea Queue Runner is different: it really
does read `idea-queue/runner-instructions.md` from main - see CLAUDE.md.)
