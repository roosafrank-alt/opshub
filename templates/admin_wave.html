Set up to three Wave accounts, tick which program each one is for, and pick each program's default. Invoice in Wave on Billing starts on the default and can swap to any other account the program has, one invoice at a time. Wave emails the invoice with its own Pay now link (card or bank, if Wave Payments is on), and OpsHub checks every half hour and marks the job or flights Paid once it's paid - always in the account it was made in.

Access token: in Wave's developer portal (developer.waveapps.com), sign in, go to Manage Applications, create an application, then open it and click Create token. One Wave login can hold several businesses: for a second business under the same login, choose Same Wave login as Account N instead of pasting the token again.
Products: Wave puts every invoice line under one of the business's products or services. Add them in Wave under Sales & Payments > Products & Services if needed (price can be $0 - OpsHub sets the price on each line), then reload this page. An account only needs the products for the programs it's used for.
